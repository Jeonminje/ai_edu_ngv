# SYS 프로세스 (시스템 엔지니어링)

각 프로세스마다: 목적(Purpose) → Base Practice(BP) → 기대 산출물(Work Product) 및 내용 지표 순으로 정리합니다.

## SYS.1 이해관계자 요구사항 도출 (Stakeholder Requirements Elicitation)

**목적**: 이해관계자로부터 요구사항을 수집하고 프로젝트 생애주기 동안 이를 유지·관리한다.

**BP**:
- 이해관계자 식별 및 요구사항 출처 확보
- 요구사항 도출 (인터뷰, 워크숍, 기존 문서 분석 등)
- 요구사항에 대한 이해관계자 합의
- 도출된 요구사항의 지속적 업데이트

**기대 산출물**:
| 산출물 | 내용 지표 |
|---|---|
| 이해관계자 요구사항 명세 | 각 요구사항에 고유 ID, 출처(이해관계자), 우선순위, 근거가 기재됨 |
| 커뮤니케이션 기록 | 요구사항 도출 활동(인터뷰/워크숍) 일시·참석자·결과가 기록됨 |
| 합의/승인 기록 | 이해관계자가 요구사항에 서명/승인한 이력 |

## SYS.2 시스템 요구사항 분석 (System Requirements Analysis)

**목적**: 이해관계자 요구사항을 시스템 요구사항으로 변환하고 구조화한다.

**BP**:
- 시스템 요구사항 명세 (기능/비기능 포함)
- 요구사항 구조화 및 분류
- 요구사항 간 상호 영향 분석
- 검증 기준(verification criteria) 정의
- 이해관계자 요구사항과의 일관성 확보
- 양방향 추적성 확립
- 요구사항 커뮤니케이션

**기대 산출물**:
| 산출물 | 내용 지표 |
|---|---|
| 시스템 요구사항 명세 | 기능/비기능 요구사항이 분리되어 있고 각 항목에 검증 기준이 연결됨 |
| 추적성 매트릭스 (이해관계자↔시스템 요구사항) | 양방향 링크가 끊김 없이 존재 |
| 영향 분석 기록 | 요구사항 변경 시 다른 요구사항/설계에 미치는 영향 분석 결과 |

## SYS.3 시스템 아키텍처 설계 (System Architectural Design)

**목적**: 시스템 요구사항을 만족하는 아키텍처를 설계하고 요구사항을 아키텍처 요소에 배분한다.

**BP**:
- 아키텍처 설계 (구성요소, 인터페이스 정의)
- 요구사항의 아키텍처 요소 배분
- 인터페이스 정의
- 동적 동작(behavior) 기술
- 자원 사용(성능 등) 고려
- 아키텍처 대안 평가 및 선택 근거
- 요구사항과의 일관성/추적성 확립

**기대 산출물**:
| 산출물 | 내용 지표 |
|---|---|
| 시스템 아키텍처 설계서 | 구성요소, 인터페이스, 데이터/제어 흐름이 도식화됨 |
| 아키텍처 대안 평가 기록 | 최소 1개 이상의 대안과 선택 근거(트레이드오프)가 문서화됨 |
| 추적성 매트릭스 (요구사항↔아키텍처) | 각 요구사항이 하나 이상의 아키텍처 요소에 배분됨 |

## SYS.4 시스템 통합 및 통합시험 (System Integration and Integration Test)

**목적**: 시스템 구성요소를 통합하고 통합된 시스템이 아키텍처 설계를 만족하는지 검증한다.

**BP**:
- 통합 전략 수립 (통합 순서, 단계)
- 통합 검증 기준 정의
- 통합 테스트 케이스/전략 수립
- 통합 수행 및 결과 기록
- 회귀 전략 정의
- 양방향 추적성 (아키텍처↔통합테스트)

**기대 산출물**:
| 산출물 | 내용 지표 |
|---|---|
| 통합 전략/계획 | 통합 순서, 각 단계의 진입/종료 기준 명시 |
| 통합 테스트 명세 및 결과 | 테스트 케이스가 아키텍처 요소/인터페이스와 매핑되고, 실행 결과(Pass/Fail)가 기록됨 |
| 회귀 테스트 전략 | 변경 시 재테스트 범위 결정 기준 |

## SYS.5 시스템 자격시험 (System Qualification Test)

**목적**: 통합된 시스템이 시스템 요구사항을 만족하는지 검증한다.

**BP**:
- 자격시험 전략/기준 수립
- 시험 케이스가 시스템 요구사항을 커버하도록 설계
- 시험 환경 정의
- 시험 수행 및 결과 기록
- 양방향 추적성 (시스템 요구사항↔자격시험)

**기대 산출물**:
| 산출물 | 내용 지표 |
|---|---|
| 시스템 자격시험 명세 | 각 시스템 요구사항에 최소 1개 이상의 테스트 케이스가 매핑됨 |
| 시험 결과 보고서 | Pass/Fail, 결함 연결, 재시험 이력 포함 |
| 추적성 매트릭스 (시스템요구사항↔자격시험) | 커버리지 갭이 명시적으로 식별됨 |
